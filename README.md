# 宝可梦水银 FC 存档修改器

一个纯静态、单文件的《宝可梦水银》FC 版（如 1.33）`.sav` 存档修改器。所有读写都在浏览器本地完成，不上传任何数据，无需安装、无需服务器。

## 在线使用

打开 **https://ttt2718.github.io/azoth-save-editor/** 即可。

也可以直接下载本仓库的 `index.html`，双击用浏览器打开，完全离线使用。

## 功能

- **金钱 / 代币**：直接修改，支持一键拉满。
- **背包 · 培育道具**：添加/修改/删除道具及数量（含一键神奇糖果，数量最大支持 999）。
- **箱子宝可梦（全部 25 箱）**：种类、昵称（中文）、持有道具、经验/等级、招式、IV/EV、亲密度、特性、性格、闪光，支持新增与清空格子。
- **队伍宝可梦**：同上字段；修改等级会同时写入经验值与等级字段，并按游戏公式重算 HP 和六项能力（应用后当前 HP 回满）。
- 内嵌全部宝可梦图标、图鉴/道具/招式/特性数据与中文字库，单文件即可运行。
- 写出时同步更新存档的当前份与备份份并重建扇区校验和，文件大小及末尾 16 字节附加数据保持不变。

针对本作已特殊适配的地方：

- 性格顺序与原版不同，以 ROM 内名称表为准（含“孤独”“稳重”等本作叫法），并标注 ±能力修正。
- 箱子为自定义 58 字节明文格式；队伍为 100 字节明文格式，均不按原版火红加密算法处理。
- 箱子 20–25 分布在特殊扇区与 SaveBlock1/2 的自定义位置。

## 使用方法

1. **先备份你的原 `.sav` 文件。**
2. 打开页面，选择或拖入 `.sav` 电池存档（131072 字节，或带 16 字节附加数据的 131088 字节；不要使用即时存档 .ss1 等）。
3. 修改金钱、背包、箱子或队伍内容。
4. 点击「生成修改后的存档」→「下载修改后的存档」（手机 Delta 用户请改用自动出现的「下载 Delta 兼容版」，已去掉 RTC 附加数据，文件名需与 ROM 一致）。
5. 用下载的文件替换原存档（与 ROM 同名同目录）。
6. **完全重启模拟器后正常读档**，切勿从即时存档恢复，否则旧内存会覆盖修改结果。

## 注意

- 仅支持水银 **FC 版**存档，不支持新版对战塔（BAG16/PC18）格式。
- 队伍暂不支持新增/删除成员；箱子支持。
- 道具数量 999 可以存储，但超出游戏常规 99 堆叠的表现请自行测试，异常时改回 99。
- 修改性格/特性/闪光通过重算 PID 实现，会尽量保持其余属性（性格、闪光、性别与特性位）不变。
- 修改前请务必备份；使用本工具产生的任何后果由使用者自行承担。
